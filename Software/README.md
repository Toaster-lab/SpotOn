# Run SpotOn locally

## Before you Start
Please make sure to have NodeJS installed on the target device.

## How to run the App

> [!NOTE]
> This Project is based on Vite and npm, a front end Tool.
> You can read more here: https://vite.dev/

1. Clone the Repo locally or download it as a zip (In this case, unzip it)
2. Open the Terminal in the Software folder of the app
3. Install the dependencies with:
```npm install```
5. Start the App with:
```npm run dev```

## How to access the website

> [!NOTE]
> This project is hosted locally. Therefore, it is avaiable via Localhost. Please make sure the app is running before trying to access it via the browser.

1. Open up a Browser Tab
2. Access the website with the URL: `http://localhost:5173/`
3. Enjoy!
